# Plant Monitoring SaaS

Магистерский проект: **SaaS-система для слежения за растениями и анализа данных через мобильное приложение**.

Проект является развитием выпускной квалификационной работы и представляет собой frontend-прототип мобильного приложения для мониторинга состояния растений с использованием IoT-устройств на базе ESP32.

## Описание проекта

**Plant Monitoring SaaS** — это прототип системы, в которой пользователь может добавлять растения, подключать к ним устройства на базе ESP32, просматривать показатели датчиков, анализировать историю измерений и получать рекомендации по уходу.

В текущей версии реализована мобильная часть приложения на **Expo / React Native**. Данные временно сохраняются локально на устройстве через **AsyncStorage**. В дальнейшем локальное хранение планируется заменить на backend API и базу данных.

## Основная идея

Система строится по следующей логике:

```text
ESP32 + датчики
↓
Backend API
↓
База данных
↓
Мобильное приложение
↓
Пользователь
```

ESP32-устройство собирает данные с датчиков и передает их на сервер. Сервер сохраняет телеметрию, анализирует показатели и предоставляет данные мобильному приложению. Пользователь видит текущее состояние растений, графики, историю измерений и рекомендации.

## Реализованный функционал

На текущем этапе реализовано:

- экран списка растений;
- добавление нового растения;
- локальное сохранение растений;
- экран устройств ESP32;
- добавление устройства;
- привязка устройства к растению;
- локальное сохранение устройств;
- подробная карточка растения;
- отображение текущих показателей датчиков:
  - влажность почвы;
  - температура воздуха;
  - освещенность;
- история измерений;
- линейные графики изменения показателей;
- анализ динамики показателей;
- экран советов и рекомендаций;
- экран профиля;
- сброс демо-данных;
- in-app уведомления вместо системных alert-сообщений;
- подготовленный API-слой для будущего backend.

## Основные экраны

### Растения

Экран отображает список растений пользователя. Для каждого растения показываются:

- название;
- тип;
- местоположение;
- текущий статус;
- влажность почвы;
- температура воздуха;
- освещенность;
- краткая рекомендация.

### Добавление растения

Пользователь может добавить растение, указав:

- название;
- тип растения;
- местоположение.

В текущей версии данные сохраняются локально.

### Устройства ESP32

Экран предназначен для управления IoT-устройствами. Пользователь может:

- добавить ESP32-устройство;
- указать Device ID;
- привязать устройство к конкретному растению;
- видеть статус устройства.

### Карточка растения

Карточка растения содержит:

- текущие показатели датчиков;
- рекомендацию;
- анализ динамики;
- линейные графики;
- историю измерений;
- информацию о подключенном устройстве.

### Советы

Экран советов формирует рекомендации на основе простых правил:

```text
Если влажность почвы < 30% → рекомендация проверить полив
Если температура < 18°C → рекомендация повысить температуру
Если освещенность < 300 lx → рекомендация улучшить освещение
Если устройство не подключено → рекомендация подключить ESP32
```

### Профиль

Экран профиля содержит:

- информацию о режиме прототипа;
- количество растений;
- количество устройств;
- кнопку сброса демо-данных.

## Установка и запуск

Сначала установите зависимости:

```bash
npm install
```

Запуск проекта:

```bash
npm start
```

или:

```bash
npx expo start
```

Для запуска в браузере после старта Expo нажмите:

```text
w
```

```bash
npx expo start -c
```

## Локальное хранение данных

В текущей версии данные растений и устройств сохраняются локально через **AsyncStorage**.

Это позволяет:

- добавлять растения;
- добавлять устройства;
- сохранять данные после перезагрузки страницы или приложения;
- сбрасывать демо-данные через экран профиля.

В будущем этот слой будет заменен на взаимодействие с backend API.

## API-заготовки

В проект добавлена папка `api`, которая подготавливает приложение к будущему backend.

Пока API-файлы являются заглушками:

- `plantApi.js`;
- `deviceApi.js`;
- `telemetryApi.js`;
- `authApi.js`.

В дальнейшем в них будут добавлены реальные HTTP-запросы.

Планируемые API-методы:

```text
POST /auth/register
POST /auth/login

GET /plants
POST /plants
GET /plants/:id

GET /devices
POST /devices
POST /devices/:id/bind

POST /telemetry
GET /plants/:id/telemetry
GET /plants/:id/recommendations
```

## Работа с ESP32

В будущей версии ESP32 будет отправлять данные на backend.

Пример передаваемых данных:

```json
{
  "deviceCode": "esp32-001",
  "soilMoisture": 42,
  "temperature": 23.5,
  "light": 680
}
```

Backend будет сохранять эти данные в базу, а мобильное приложение будет получать историю измерений и рекомендации через API.

## Текущий статус проекта

Проект находится на стадии **frontend-прототипа**.

Сейчас приложение работает без реального backend-сервера. Для демонстрации используются mock-данные и локальное сохранение через AsyncStorage.

Текущая архитектура данных:

```text
Screens
↓
Context
↓
localStorageService
↓
AsyncStorage
```

Планируемая архитектура:

```text
Screens
↓
Context
↓
API layer
↓
Backend
↓
Database
```
